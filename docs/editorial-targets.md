## Regra de produção

Variar bairro, dor do cliente, tipo de imóvel e empreendimento em cada ciclo.
Pesquisar preço por m², valorização, comércio, restaurantes, praia, mobilidade e
pontos de interesse conforme o tema; números exigem fonte, data e método.
Rascunhos ficam como `DRAFT`. Publicação exige comando posterior do usuário.
Todo link comercial aponta para página própria comprovada, nunca para construtora.
